## Wie du das hier nutzt

Leg einfach ab, was du hast — ein Word-Dokument mit Textänderungen, ein paar Fotos
vom letzten Run, eine Sprachnachricht als Datei. Sag danach, was damit passieren
soll. Neue Fotos gehören zusätzlich nach `assets/images/_originals/`, damit
`tools/optimize_images.py` sie fürs Web aufbereiten kann.

Sinnvoll ist eine Datei pro Thema und ein Datum im Namen, etwa
`2026-08-15-textaenderungen.docx`. Dann bleibt nachvollziehbar, was wann kam.
